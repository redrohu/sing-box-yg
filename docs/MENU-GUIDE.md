## 读图规则

- VPS 与 Serv00 是两个独立的 `sb` 菜单，不能混用编号；图中 Serv00 路径用 `S→` 前缀区分，实际输入时不输入 S。
- “表单”“证书”“端口”等文字路径表示交互步骤，不是隐藏的数字菜单。`0`、`3 返回`和 `y/n` 以各级实际提示为准。
- Sing-box 五协议：VLESS REALITY / VMess WS / Hysteria2 / TUIC5 / AnyTLS；1.10 分支不含 AnyTLS。
- 两种 XHTTP 是独立 Xray 服务，不受 Sing-box UUID、启停、端口、出站分流与内核切换控制；主菜单 2 完整卸载会移除。
- Mihomo YAML / 通用 URI 含已部署 XHTTP；官方 Sing-box JSON 不写入 XHTTP。客户端必须支持所选模式；配置导出通过不等于公网连接成功。
- 订阅/密钥/Token/管理令牌都视为敏感信息；本图只使用字段名和默认值，不含真实凭据。

| 4→4→3 | 删除TUIC多端口 | 仅清理识别为本项目的相关端口转发。 |
| 4→5 | 更改AnyTLS主端口 | 只在非1.10分支显示；只有一个主端口。 |
| 4→0 | 返回主菜单 | HY2/TUIC子菜单及添加子菜单各自0返回上层，不涉及独立XHTTP。 |

### 5　域名分流：通道 → 匹配方式

| 输入路径 | 功能 | 说明与限制 |
| --- | --- | --- |
| 5→1 | Warp WireGuard IPv4优先 | 仅1.10分支可用。 |

| 5→4 | 本机SOCKS5 IPv6优先 | 仅1.10分支可用。 |
| 5→5 | VPS本地IPv4优先 | 走本地出站，仍受当前可用地址族限制。 |
| 5→6 | VPS本地IPv6优先 | 走本地出站，仍受当前可用地址族限制。 |
| 5→通道→1 | 按后缀域名匹配 | 空格分隔，如example.com；回车清空该通道规则。 |
| 5→通道→2 | 按geosite规则匹配 | 仅1.10分支可用；现代分支仍可能显示选项2，但选择后拒绝。 |
| 5→通道→3 | 返回通道选择 | 不要把同一个域名/规则重复放入多个通道。 |

**本页提醒：**

- 安装防火墙步骤1会关闭/清理防火墙规则，影响不止本脚本；已有其他业务建议选2自行放行。
- 5→分流：1.10支持1–6通道与geosite；现代分支1、4不可用。geosite选项可能仍显示，但选择会被拒绝。
- 分流通道不可用时目标网站可能被阻断；这些规则只作用于Sing-box五协议，独立XHTTP仍走独立出站。
