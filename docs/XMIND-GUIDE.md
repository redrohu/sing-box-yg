## 如何直接了解作用和风险

- 数字主题对应实际数字菜单；连线表示真实所属关系，而不是专题归类。
- **【作用 / 说明】**和**【注意】**是可见子主题，不只放在备注中，也不是可输入的菜单编号。
- 安装是顺序交互流程，用“步骤 / 输入”标记；流程里的1、2等选择与日常管理子菜单区分开。
- XHTTP的部署模式选择、Cloudflare准备挂在“部署”下面，不再制造数字子菜单。
- 主菜单11/12/13调用外部在线脚本；本仓库只提供入口，所以明确说明作用与风险，不编造外部脚本的实时子菜单。
- 主菜单0与各层返回项都在所属位置；遇到XHTTP单次操作后结束、不自动重绘菜单等行为，会显示说明。
- 第2个画布是独立的Serv00菜单，第3个是Serv00管理API。它们不混入VPS的0–16，也不伪装成SSH数字菜单。
- 所有说明保持在相应菜单分支下。较大分支可在XMind折叠、展开或缩放，主题仍可编辑。

```powershell
python docs/build_xmind_guide.py
python docs/build_xmind_guide.py --check
python -m unittest discover -s tests -p test_xmind_guide.py -v
```

这个可选渲染脚本需要Pillow及Windows微软雅黑字体，不影响标准库生成XMind。

导出使用Python标准库。`menu_tree.py`将共享说明映射到真实菜单路径，并补上实际返回项与条件。
校验包括：主菜单顺序、3→11→9→8父子关系、各通道匹配子菜单、167条说明覆盖、可见注意事项、唯一ID及可重复生成。
`--check`比对菜单内容与父子关系，允许XMind正常保存的主题、样式和缩略图差异，不会改写文件。
不带`--check`的生成命令会重新生成文件，手工调整样式后请先备份再执行。
