## 3. 菜单查询缓存与并发

| 信息 | TTL | 行为 |
| --- | --- | --- |
| IPv4 / IPv6 / 两个地区查询 | 60 秒 | 四路并发，单路连接 2 秒、总体 5 秒；完整成功结果才入缓存 |
| Sing-box 可用正式/测试版本 | 300 秒 | 元数据失败回退原发布页；无法验证时不写缓存 |
| 脚本版本及整份更新日志 | 300 秒 | 缓存同一份响应，避免版本号与日志混用不同响应 |
| 本机已安装核心版本 | 不缓存 | 每次读当前二进制，避免安装/切换后显示旧版本 |

缓存是 `/etc/s-box/cache/menu-*.json`，目录权限 `700`，文件通过权限受限的临时文件替换。读取时检查类型、时间、IP/版本字段；不 `source` 或 `eval` 缓存。过期或损坏缓存会重新查询，网络失败不把旧缓存假称为当前查询成功。单栈主机因缺少另一地址族可能不会命中完整网络缓存，这是避免长期固化瞬时失败的保守取舍。

需要立即刷新菜单时：

```bash
SB_MENU_REFRESH=1 sb
```

刷新本地 IP/改变网络输出、Warp 操作及进入核心更新选择时会主动绕过相应缓存。实际脚本/内核下载、摘要验证、安装和启动检查不使用菜单缓存。暖缓存减少请求和菜单等待，**不代表代理节点吞吐提高**。
